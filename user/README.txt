This directory holds user-defined configuration for UI modules.

Each file should be named <module>.js (or <module>.ts) for variables and
<module>.css for layout/style settings where <module> is the name of the module
that will load the config.  Files in a <module> folder here are loaded too.

Copy and rename the <module>-example.js file to <module>.js for an easy
starting point.  raidboss-typescript-example.ts is a TypeScript one, written like
cactbot's own trigger files (which can be copied here as they are).
